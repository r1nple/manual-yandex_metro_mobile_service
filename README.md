# <a name="up" />Проект 4-го спринта по ручному тестированию - тестирование мобильного приложения Яндекс.Метро для Android
Команда Яндекс Метро провела рефакторинг мобильного приложения на Android — внесла правки в код. Чтобы выпустить новую версию, предварительно нужно: протестировать те части продукта, которых коснулись изменения; провести регрессионное тестирование и убедиться, что новую версию можно заливать в стор.

## Задачи тестировщика

<details>
  <summary>Задачи проекта 4-го спринта</summary>
  
  #### Задачи
  1. Подготовка к функциональному тестированию, nребования, которые затронул рефакторинг приложения, выделили полужирным шрифтом. Теперь нужно написать к ним тесты. Оформить проверки в виде чек-листа.
  2. Подготовка к регрессионному тестированию, кроме проверок функциональности, затронутой рефакторингом, нужно провести регрессионное тестирование. Для этого написать чек-лист, который учитывает особенности мобильного приложения.
  3. Выполнение тестирования, протестировать мобильное приложение по своим чек-листам. Завести баг-репорты на последней вкладке своей копии Google-таблицы. Конфигурация для тестирования: **Honor 8, ОС Android 9.0 Pie; разрешение экрана 1080×1920; диагональ 5.5.** **Важно:** тестирование проводи на эмуляторе Android Studio. Но если у тебя есть физическое устройство под управлением Android версии 9 — тестировать можно на нём.
  4. Отчёт о тестировании. Оформить проделанную работу в виде отчёта.

  Ссылки для работы:

<a href="https://code.s3.yandex.net/qa/files/yandexmetro-android-v2.13.apk" target="_blank">Текущая версия приложения</a>, которую пользователи скачивают из стора;

<a href="https://code.s3.yandex.net/qa/files/yandexmetro-android-v3.6.apk" target="_blank">Готовящаяся сборка</a>;

</details>
